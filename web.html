Web Development

A personal summary of what I've studied in HTML, CSS, and JavaScript.

7 Days of Learning
✅ Status: Completed
🛠️ Skills: HTML, CSS, JavaScript
🎯 Final Project: To-Do List App
DAY 1 Foundation with Basic HTML Tags

On the first day, the focus was on understanding the structural backbone of a webpage. I learned how to use essential HTML tags to display and format text content.

📌 Topics Covered
<html> <head> <body> <p> <b> <i> <marquee>
📝 Assignment

A basic webpage demonstrating text-based content with various formatting styles.

DAY 2 Multimedia & Data Representation

The second day focused on making web pages interactive and informative by integrating media and structured data.

📌 Topics Covered
<img> <a> <audio> <video> <table> <tr> <td> <th>
📝 Assignment

A multimedia gallery page and a structured student timetable or data sheet.

DAY 3 User Interaction with Forms

Day 3 was dedicated to learning how to collect and process user data through web forms.

📌 Topics Covered
<form> text input password email radio checkbox <select> <button>
📝 Assignment

A comprehensive User Registration form with various input validations.

DAY 4 Semantic Layout & CSS Selectors

On Day 4, I transitioned into styling and layout organization, focusing on how to target specific elements using CSS.

📌 Topics Covered
<header> <nav> <footer> Universal Selector Element Selector Class Selector ID Selector Attribute Selector
📝 Assignment

A structured webpage layout with a styled navigation bar and distinct header/footer sections.

DAY 5 Layout Control: Box Model & Flexbox

This day focused on the core concepts of modern web design: spacing, alignment, and responsiveness.

📌 Topics Covered
Margin Border Padding Content display: flex justify-content align-items flex-direction
📝 Assignment

A responsive grid or a "Product Card" layout designed using Flexbox.

DAY 6 Logic Building with JavaScript Basics

On Day 6, I began adding functionality to static pages using JavaScript to perform logical operations.

📌 Topics Covered
let const Data Types Arithmetic Operators Logical Operators Functions
📝 Assignment

An interactive script, such as a basic arithmetic calculator or a dynamic greeting system.

DAY 7 Capstone Project: To-Do List App

The final day involved combining all previous skills to build a functional, dynamic web application.

📌 Topics Covered
DOM Manipulation Event Listeners click submit Array Methods
📝 Assignment

A fully functional To-Do List App that allows users to add, track, and delete tasks in real-time.
