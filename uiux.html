UI/UX Design

A personal journey through User Interface and User Experience Design — from fundamentals to real-world projects, Day by Day.

📅 5 Days of Learning
✅ Status: Completed
🛠️ Tool: Figma
🎯 Final Project: UI/UX Design
DAY 1 Introduction to UI Design

Day 1 was about understanding what UI Design means — creating interfaces that are visually appealing and easy to use. We explored core design building blocks and got introduced to Figma as our design tool.

📌 Topics Covered
What is UI Design UI vs Graphic Design Design Principles Typography Color Theory Spacing & Layout Figma Basics Frames & Layers
📝 What I Learned

UI Design is about creating clean, consistent interfaces. Learned how typography, color and spacing impact user experience. Figma is the go-to tool for professional UI design.

DAY 2 Project 1 — Red Bull Page Design

Day 2 was hands-on — we recreated a Red Bull landing page UI in Figma. Red Bull's bold, energetic brand taught me how brand identity directly influences design decisions.

📌 Topics Covered
Landing Page Design Brand Identity Hero Section Dark Theme Design Visual Hierarchy Button Styling Image Placement Figma Components
📝 Project

Designed a Red Bull inspired landing page in Figma — bold hero section, strong typography and a call-to-action button matching Red Bull's energetic brand.

DAY 3 Glass Morphism

Day 3 was the most visually exciting — we learned Glass Morphism, a modern UI trend that creates a frosted glass effect using transparency, blur and subtle borders.

📌 Topics Covered
Glass Morphism Frosted Glass Effect Background Blur Transparency & Opacity Subtle Borders Gradient Backgrounds Card UI Design Figma Effects
📝 What I Learned

Glass Morphism uses background blur, low opacity fill and light borders to create a frosted glass look. Designed glass-style cards in Figma using layering and depth.

DAY 4 Introduction to UX Design

Day 4 shifted focus from how things look to how things feel. UX is about the complete user experience — a beautiful UI with poor UX will still frustrate users.

📌 Topics Covered
What is UX Design UI vs UX User Research User Personas User Journey Map Wireframing Usability Design Thinking
📝 What I Learned

UX focuses on how easy a product is to use. Key concepts: User Personas, User Journey Maps and Wireframes. Good UX starts with understanding what the user actually needs.

DAY 5 Final Project — UI/UX Design

Day 5 was the grand finale — everything came together into one complete UI/UX project. Designing with purpose and keeping the user in mind was the key focus.

📌 Topics Covered
Full Page UI Design Design System Color Palette Component Reuse Layout & Spacing UX Thinking User Flow Final Presentation
📝 Final Project

Designed a complete multi-screen UI/UX project in Figma — consistent components, clear hierarchy and smooth user flow, combining all skills from Day 1 to Day 4.
